# 知识库笔记格式

笔记给以后的自己查，所以只放改写后的五格内容，不放聊天过程。Obsidian、Notion、任何 Markdown 工具都能直接用。

```markdown
---
title: <标题>
date: <YYYY-MM-DD>
source: <原文来自哪里：哪个对话 / 哪个文件 / 哪个链接>
tags: [看懂]
---

# <标题>

> 读者问题：<第 1 步写下的那一句>
> 页面：[<标题>.html](<标题>.html)

## 结论
<最多 3 句>

## 概念
- **<名字>**：<一句解释>。别名：<原文里出现过的其他叫法，没有就省略>

## 关系
<一两句说明全局图画的是什么关系>

## 细节
### <概念名>
- ...

## 待定
- [ ] <问题>（选项：A / B）
```

规则：

- 概念名和页面上的名字一字不差。
- 没有待定事项就删掉「待定」一节。
- 文件名和标题里不要出现 `/ : * ? " < > |`。
